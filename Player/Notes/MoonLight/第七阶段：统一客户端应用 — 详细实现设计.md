# 第七阶段：统一客户端应用 — 详细实现设计（v2 架构重组版）

> MainWindow 持有 QStackedWidget + TitleBar，PlayerApp 只管引擎，Server UI 与引擎分离。

## 1. 架构原则

| 原则 | 说明 |
|------|------|
| MainWindow 是 UI 根 | 持有 QStackedWidget + TitleBar，管理所有页面导航 |
| PlayerApp 只管引擎 | 创建 MainWindow、管理 FFmpegPlayer 生命周期，不碰 QStackedWidget |
| 引擎与 UI 分离 | `Server/` 纯引擎，`Client/ServerUI/` 放被控端面板 |
| 页面通过 MainWindow 解耦 | 各页面只发信号，MainWindow 统一切换 |

## 2. 组件树

```
MainWindow（主窗口）
  ├── TitleBar（固定顶部，跨页面复用）
  │     ├── 标题：根据当前页面动态切换
  │     ├── 返回按钮：非 LaunchPage 时显示
  │     └── 最小化 / 关闭
  │
  └── QStackedWidget
        ├── [0] LaunchPage      启动页
        ├── [1] PlayerPage      播放器页面
        ├── [2] ConnectDialog   控制端连接
        ├── [3] StreamWindow    控制端串流画面
        └── [4] ServerPanel     被控端面板
```

## 3. 信号流

```
LaunchPage.SigPlayerMode      ──→ MainWindow.SwitchToPlayer()
LaunchPage.SigControllerMode  ──→ MainWindow.SwitchToController()
LaunchPage.SigServerMode      ──→ MainWindow.SwitchToServer()

ConnectDialog.SigConnect(ip, port, ctrl, fps) ──→ MainWindow
  │→ MainWindow.SwitchToStream(sw)
  └→ PlayerApp.StartStream(ip, port, ctrl, fps)

任意页面.SigBack ──→ MainWindow.SwitchToLaunch()
  └→ PlayerApp.DestroyPlayer()
```

## 4. PlayerApp（精简后）

```cpp
class PlayerApp : public QObject
{
    Q_OBJECT
public:
    void Init();                            // 创建 MainWindow → 显示

    // 引擎管理（由 MainWindow 页面调用）
    void StartPlayer(const QString& path = "");     // 播放器模式
    void StartStream(const QString& ip, uint16_t port,
                     uint16_t ctrl_port, int fps);  // 控制端模式
    void DestroyPlayer();

private:
    MainWindow* main_window_{nullptr};      // 唯一窗口
    FFmpegPlayer* player_{nullptr};         // 播放器引擎

    // 内部
    void CreatePlayer();                    // 创建 FFmpegPlayer + 绑定信号
    void CreateStreamPlayer(StreamWindow* sw);
};
```

## 6. PlayerPage（新，拆分自旧 MainWindow）

**说明**：PlayerPage 只负责**UI 布局和控件暴露**，不持有 FFmpegPlayer。所有播放逻辑由 PlayerApp 通过绑定信号实现，代码从旧 PlayerApp::BindPlayerSignals() 平移到 MainWindow 或 PlayerApp。

## 11. 实测修复（2026-08-01 真机联调）

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | 双标题栏 | StreamWindow 自带 TitleBar，嵌入 MainWindow 后重复 | `StreamWindow::SetEmbedded(true)` 隐藏内部标题栏 |
| 2 | 本机 IP 显示虚拟网卡 | `getaddrinfo` 返回第一个地址（Tailscale 169.254） | 遍历所有地址，跳过 APIPA/回环，优先 192.168/10/172.16 |
| 3 | 显示器默认索引 1 | 硬编码 `monitor_index=1`，单显示器时报错 | 动态枚举 `MonitorCapture::EnumerateMonitors()`，QComboBox 选择 |
| 4 | UDP 包不出发网卡 | `dest_ip` 硬编码 `127.0.0.1` | 新增目标 IP 输入框，持久化到 QSettings |
| 5 | 状态栏"已连接"在失败时也显示 | `SigLoaded` 无条件设 `已连接`；timer 不经检查调 `OnStreamReady` | 三级状态推进：等待连接→编解码就绪→控制信道就绪/失败 |
| 6 | 断线后 UI 不刷新 | `client_connected_` 只在收到消息时置 true，不断开时置 false | InputTransportServer 新增 `OnClientDisconnected` 回调 |
| 7 | SetBitrate 一直失败 | `av_opt_set(priv_data, "b")` 在 NVENC 上不存在 | 改为直接设 `codec_ctx_->bit_rate` |
| 8 | 最近连接帧率解析错误 | `"120@120fps".toInt()` 返回 0→兜底成 10 | 用 `Qt::UserRole` 存纯数字格式，LoadRecent 加旧格式迁移 |
| 9 | 最近连接不保存帧率 | 旧格式只有 `ip:port:ctrl_port` | 新格式 `ip:port:ctrl_port:fps`，显示 `ip:port @ fpsfps` |
| 10 | 键盘在窗口外仍响应 | `WH_KEYBOARD_LL` 全局钩子无前台窗口检查 | `KeyboardProc` 加 `GetForegroundWindow()` 判断 |
| 11 | IP 不可复制 | QLabel 默认不可选中 | `setTextInteractionFlags(Qt::TextSelectableByMouse)` |
| 12 | 最近连接不可删除 | 无右键菜单 | `CustomContextMenu` + "删除"菜单项 |
