# 用户交互：播放器 UI 控制实现笔记

## 架构

```
MainWindow（QWidget，无边框窗口）
  ├── TitleBar（标题栏：拖拽移动 + 最小化/全屏/关闭按钮）
  ├── VideoWidget（视频渲染区域：HWND + 软解 QLabel）
  └── ControlBar（底部控制栏：播放按钮 + 进度条 + 时间标签 + 音量滑块）
```

---

## 标题栏（TitleBar）

三个按钮 + 拖拽移动窗口：

| 按钮        | 行为                   |
| ----------- | ---------------------- |
| 最小化（—） | `showMinimized()`      |
| 全屏（□）   | `ToggleFullScreen()`   |
| 关闭（✕）   | `QApplication::quit()` |

拖拽事件：`mousePressEvent` 记录起点，`mouseMoveEvent` 移动 `parentWidget()`。

## 全屏沉浸模式

功能拆分：

| 条件                | 行为                                                         |
| ------------------- | ------------------------------------------------------------ |
| 按 F 或点击全屏按钮 | `ToggleFullScreen()`：隐藏 TitleBar + ControlBar，`showFullScreen()` |
| 按 Esc              | 退出全屏，恢复 TitleBar + ControlBar                         |
| 全屏下鼠标移动      | 显示 TitleBar + ControlBar，启动 2 秒计时器                  |
| 2 秒后鼠标静止      | 隐藏 TitleBar + ControlBar                                   |

实现方式：

```cpp
// eventFilter 中拦截 MouseMove
if (fullscreen_ && event->type() == QEvent::MouseMove)
{
    title_bar_->show();
    control_bar_->show();
    mouse_idle_timer_->start(2000);
}

// OnMouseIdle 触发时检查鼠标位置
void MainWindow::OnMouseIdle()
{
    QPoint cursor = mapFromGlobal(QCursor::pos());
    if (!title_bar_->geometry().contains(cursor) &&
        !control_bar_->geometry().contains(cursor))
    {
        title_bar_->hide();
        control_bar_->hide();
    }
}
```

需要为窗口和所有子控件启用 `setMouseTracking(true)`，否则 `MouseMove` 只在按下时触发。

## 进度条拖动（seek）

### 核心机制：serial 序列号

`SafeQueue` 新增 `serial_` 成员和 `Flush()` 方法：

```cpp
void Flush()
{
    std::lock_guard<std::mutex> lock(mutex_);
    while (!queue_.empty()) queue_.pop();
    serial_++;
}
```

`Flush()` 清空队列的同时自增序列号。解码线程通过检测 serial 变化来自动 flush：

```cpp
// VideoDecodeLoop 和 AudioDecodeLoop 中
int cur_serial = packet_queue_.serial();
if (cur_serial != last_serial_)
{
    avcodec_flush_buffers(decoder_ctx);
    frame_queue_.Clear();
    last_serial_ = cur_serial;
}
```

### Seek 流程

```
用户松开进度条 → sliderReleased → player->Seek(30000)
  └→ reader_.Seek(30000)           // 设原子变量
  └→ frame_timer = now()           // 重置帧计时器
  └→ last_frame_pts = 0

Reader 检测到 seek_target_ms_：
  └→ av_seek_frame()               // FFmpeg 跳转
  └→ video_packet_queue_.Flush()   // serial++
  └→ audio_packet_queue_.Flush()   // serial++

解码线程发现 serial 变化：
  └→ avcodec_flush_buffers()       // 自动清理解码器
  └→ frame_queue_.Clear()          // 清空旧帧
  └→ 解码新包 → 推新帧

DecodeLoop 取到新帧：
  └→ 新 PTS ≈ 30000ms，正常显示
```

整个过程中不需要暂停声卡、不需要手动 flush 解码器、不需要清空帧队列。serial 机制自动处理一切。

### 用户交互

| 操作     | 触发信号                  | 行为                                                         |
| :------- | :------------------------ | :----------------------------------------------------------- |
| 拖拽滑块 | `QSlider::sliderMoved`    | 更新时间标签 + 执行 seek                                     |
| 点击轨道 | `ControlBar::eventFilter` | 计算点击位置对应的值 → 设滑块值 → 发射 `SigSeekRequested` → 执行 seek |

`sliderPressed` 时停止进度轮询，`sliderMoved` 和 `SigSeekRequested` 中执行 seek 后恢复轮询。

`eventFilter` 中用 `QStyle::sliderValueFromPosition` 将点击的像素位置转为进度值，解决 QSlider 不响应轨道点击的问题。

## 音频时钟

### 问题

Qt 的 `processedUSecs()` 是一个只增不减的硬件计数器——声卡播了多少数据它就累计多少。seek 到新位置后它不会跳变到新时间，而是从旧值继续缓慢增长，导致 30 多秒的同步错乱。

### 解决方案

自己维护音频时钟，基于帧的 PTS 计算：

```cpp
// FeedFrame 中
double frame_duration_ms = (double)frame->nb_samples / frame->sample_rate * 1000.0;
if (frame->pts != AV_NOPTS_VALUE)
{
    audio_clock_ = (double)frame->pts / frame->sample_rate * 1000.0 + frame_duration_ms;
}

// GetClock 中（不再减缓冲时长）
if (audio_clock_ <= 0.0) return 0.0;
return audio_clock_;
```

seek 后新帧的 PTS 跳到 30 秒，`audio_clock_` 立刻跳到 30 秒，diff 瞬间恢复。

### `GetPosition()` 改进

```cpp
qint64 FFmpegPlayer::GetPosition() const
{
    if (audio_renderer_ && audio_renderer_->IsOpened())
    {
        qint64 clock = static_cast<qint64>(audio_renderer_->GetClock());
        return std::max(clock, current_pts_ms_.load());
    }
    return current_pts_ms_.load();
}
```

进度条始终显示 `max(audclk, current_pts_ms_)`，防止 seek 后进度条回弹。

## 音量控制

`AudioRenderer` 新增 `SetVolume` / `GetVolume`，委托给 `QAudioOutput`：

```cpp
void AudioRenderer::SetVolume(double volume)
{
    if (!audio_sink_) return;
    volume = std::max(0.0, std::min(1.0, volume));
    audio_sink_->setVolume(volume);
}
```

UI 层 `QSlider` 范围 0~100，绑定 `player_->SetVolume(value / 100.0)`。

## 时间显示

`QTimer` 每 200ms 轮询 `player_->GetPosition()`，更新进度条和时间标签：

```cpp
// 更新时间标签
QString("%1 / %2").arg(msToTimeStr(pos_ms)).arg(msToTimeStr(dur_ms));
// 更新进度条（不触发 sliderMoved）
bar->GetSeekBar()->blockSignals(true);
bar->GetSeekBar()->setValue(pos_ms);
bar->GetSeekBar()->blockSignals(false);
```

## 样式分离

所有 UI 样式放在 `QSS/style.qss` 文件中，`PlayerApp::LoadStyle()` 加载：

```cpp
QFile qss("QSS/style.qss");
qss.open(QFile::ReadOnly | QFile::Text);
qApp->setStyleSheet(qss.readAll());
```

控件通过 `setObjectName()` 关联样式。
