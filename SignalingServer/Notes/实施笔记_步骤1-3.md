## 步骤 2: SQLite + 设备注册 API — 修复记录

| 问题 | 根因 | 修复 |
|------|------|------|
| vcpkg find_package(SQLite3) 失败 | 包名不对 | `find_package(unofficial-sqlite3 CONFIG REQUIRED)` |
| curl → {"error":"db_unavailable"} | httplib 线程无 thread_local SqlExec | `GetCurrentThreadSqlExec()` 按需创建 |
| Instance() 类型推导失败 | shared_ptr 不能 auto* | `auto cfg = GlobalConfig::Instance()` |
| LogManager::Init 非静态 | 成员函数 | `LogManager::Instance()->Init()` |
| HttpServerMgr::GetServer 不存在 | API 不同 | 直接 `http_->Post(path, handler)` |
| unique_ptr 析构不完整类型 | 前向声明 | `#include "HttpServerMgr.h"` |
| file(GLOB) 不刷新新文件 | CMake 缓存 | 删 build 重配 Ninja |
| Debug/Release 混用 | VS 多配置生成器 | 换 Ninja 单配置 |

## 步骤 4: WebSocket 推送 — 实现

### WsSession.h/.cpp (~90行) — Boost.Beast WebSocket 会话

```
创建: WsSession::Create(tcp::socket) → Start() → DoAccept()
握手: ws_.async_accept() → DoRead() 循环
注册: 客户端发 {"type":"hello","device_id":"xxx"} → Register(WsSessionManager)
读写: async_read → OnMessage(JSON) → async_write
断线: async_read error → Broadcast device_offline → Remove
```

### WsSessionManager.h/.cpp (~90行) — 设备→会话映射

```cpp
class WsSessionManager (Singleton):
  Register(device_id, session)     // 新连接替换旧连接
  Remove(device_id)                 // 断开清理
  SendToDevice(device_id, json)    // 单播
  Broadcast(json)                  // 广播所有设备
  mutex_ 保护 sessions_ map
```

### 集成 SignalingApp

```cpp
// SignalingApp.h: ws_acceptor_(io_ctx_), InitWsAcceptor(), DoAcceptWs()
// Init:      InitWsAcceptor() → bind :8081 → DoAcceptWs()
// DoAccept:  async_accept → WsSession::Create(socket) → session->Start()
```

### Boost.Beast 版本兼容修复

| 问题 | 修复 |
|------|------|
| async_accept(ws_req_) 不兼容 Beast 1.88 | 纯握手 → 客户端发 hello 注册 |
| boost::json::string_view → std::string | 显式 data()+size() 构造 |
| websocket::stream 无 get_request() | 去掉 URL 参数方案 |

### Websocket 协议

```
客户端 → 服务器:  {"type":"hello","device_id":"pc1"}
服务器 → 客户端:  {"type":"device_online","id":"pc1"}
服务器 → 所有设备: {"type":"device_offline","id":"pc1"}  (断开时)
服务器 → 目标设备: {"type":"offer","from":"ctrl","sdp":"..."}   (步骤5)
服务器 → 目标设备: {"type":"answer","from":"target","sdp":"..."} (步骤5)
服务器 → 目标设备: {"type":"ice","from":"ctrl","candidate":"..."} (步骤5)
```

## 步骤 3: STUN 服务器 — 实现

### StunServer.h/.cpp (~150行)

```
协议: RFC 5389 Binding Request/Response
监听: UDP :3478
事件: async_receive_from → async_send_to

请求 (20字节):
  [0..1]  Type=0x0001 (Binding Request)
  [2..3]  Length=0
  [4..19] Transaction ID

响应 (32字节):
  [0..1]  Type=0x0101 (Binding Success Response)
  [2..3]  Length=12
  [4..19] Transaction ID (回显)
  [20..31] XOR-MAPPED-ADDRESS (type=0x0020, len=8)
           family=0x01, xport=port^0x2112, xaddr=addr^0x2112A42F
```
